Install your Meta Pixel

Four steps. About ten minutes. No downloads or logins.

1

Enter your Meta Pixel ID

Find it in Meta Events Manager, under Data Sources. It is a 15 or 16 digit number.

2

Copy the pixel code

This is the exact block to paste. Do not edit it.
